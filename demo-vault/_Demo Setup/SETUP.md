# Calm Tasks demo Vault setup

This folder contains anonymous English content prepared for screenshots and a short product video.

## Use this folder as a new Vault

1. In Obsidian, choose **Open folder as vault** and select the `demo-vault` folder.
2. Install or copy the Calm Tasks plugin into `.obsidian/plugins/calm-tasks/` and enable it.
3. Close Obsidian or disable Calm Tasks temporarily.
4. Copy `_Demo Setup/calm-tasks-demo-settings.json` to `.obsidian/plugins/calm-tasks/data.json`.
5. Reopen Obsidian and run **Calm Tasks: Open Task Workspace**.
6. Keep the status filter on Open for the primary Agenda, Priority, and All captures.

The configured All view contains exactly three open Inbox tasks. Each custom group has four open tasks. Priority A has three tasks; B, C, and D have four each. Today, Tomorrow, +3 days, and +7 days each have four open tasks. None remains long enough to be visible below the ranked priorities.

## Recommended capture order

1. All view with Inbox, Personal, Learning, Home, and Writing visible.
2. Priority view with A–D and the beginning of None.
3. Agenda with Today, Tomorrow, August 31, and September 4.
4. A regular note such as `Demo Notes/Project Launch.md` in reading or source view.
5. Search and Smart Filters using `learning`, `writing`, or `work`.
6. Multi-selection, task context menu, group context menu, and the bottom Details panel.
7. Daily Note carry-forward using the two files in `Daily Notes/`.

The dates are based on a demo day of 2026-08-28: tomorrow is 2026-08-29, +3 days is 2026-08-31, and +7 days is 2026-09-04.
