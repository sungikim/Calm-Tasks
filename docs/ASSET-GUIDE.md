## Suggested overview video sequence

1. Open Calm Tasks in All view and briefly scroll through the groups.
2. Create a task in Inbox with Enter and add a date and priority.
3. Move the task into a group with the context menu.
4. Multi-select two tasks and drag them to another group.
5. Switch to Priority, then Agenda.
6. Type a keyword and show the short delayed search.
7. Select a task and edit it in the bottom Details panel.
8. Complete the task, then reopen it.
9. End on the full All view.

## Capture notes

- Use a fresh Vault containing only the provided demo content.
- Use the same dark theme, window size, and interface scale for every capture.
- A 1600 × 1000 Obsidian window at 100% interface scale works well for the full-window images.
- Hide account names, sync status, unrelated tabs, and operating-system notifications.
- Keep the pointer away from important text unless it demonstrates a hover or context menu.
- Crop detail shots tightly, but leave enough surrounding UI to make the interaction understandable.
- Export screenshots at 80–88% WebP quality; avoid enlarging captures after export.
