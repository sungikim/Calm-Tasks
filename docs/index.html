Calm Tasks
for Obsidian.

Calm Tasks is an Obsidian plugin that collects checkbox tasks from across your vault. Review them by date, priority, or custom group while the source stays in Markdown.

Views

Agenda, Priority, and All.

All handles groups and manual order. Agenda and Priority reorganize the same tasks for a different review.

Regular Markdown notes

Task metadata stays visible in the note.

Calm Tasks can highlight dates and A–D priorities in ordinary Markdown notes, not only in the dedicated task view. The highlighting can be turned off in plugin settings.

- [ ] Prepare the launch brief | 2026-09-03 | A
- [ ] Review the backlog | B
- [ ] Book an appointment | B | 2026-09-05

Daily Note tasks are collected in the same views. An optional setting can preserve a task's All-view placement when it moves between dated notes.
