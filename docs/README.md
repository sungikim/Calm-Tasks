# Calm Tasks website

This folder is ready to publish with GitHub Pages from `main` → `/docs`.

Before publishing:

1. Push the repository to `sungikim/Calm-Tasks`.
2. Open `index.html` locally and confirm the page and media files load correctly.
3. In the GitHub repository, select **Settings → Pages → Deploy from a branch → main → /docs**.

The page intentionally keeps a styled placeholder visible when an image or video has not been added yet.
